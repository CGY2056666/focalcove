# 专注小窝 Android MVP 上线验收清单

只有“阻断项”全部通过后才能把 APK 交给实际用户。每次验收记录日期、代码
提交、APK SHA-256、服务器 release 路径和执行人，不用口头结论代替结果。

## 一、代码与自动化阻断项

- [ ] Git 工作区干净，部署提交已经记录。
- [ ] Python 全量测试全部通过。
- [ ] Android `clean testDebugUnitTest assembleDebug lintDebug` 成功。
- [ ] Android Lint 为 0 error。
- [ ] APK 签名验证通过，记录证书和 APK SHA-256。
- [ ] APK 包名为 `com.focuscompass.app`，`minSdk=29`、`targetSdk=36`。
- [ ] 源码与 APK 静态扫描不存在模型 API Key、私钥、明文密码或截图文件。

## 二、服务器上线阻断项

- [ ] 现有网页版代码和运行数据已备份，备份校验通过。
- [ ] 新移动运行卷为空，不包含开发机账号、历史和 `.env`。
- [ ] `FOCUS_APP_SECRET` 为服务器随机生成值，至少 32 字符。
- [ ] 模型 API Key 只存在于服务器环境文件，权限为 `600`。
- [ ] `FOCUS_EVAL_CAPTURE_ENABLED=false`。
- [ ] Gunicorn 为 1 worker；移动容器只监听 `127.0.0.1:8001`。
- [ ] Nginx `nginx -t` 通过后才 reload。
- [ ] Nginx 对 `/api/v1/` 关闭请求缓冲，不把截图写入临时文件。
- [ ] 未登录移动接口返回统一 401 JSON，而不是 404 或 HTML。
- [ ] 专用测试账号的登录、bootstrap、开始、查询、放弃和退出冒烟全部通过。
- [ ] 现有网页版登录、首页、开始专注和历史页面仍能访问。

## 三、APK 配置阻断项

- [ ] APK 构建地址为实际部署的 HTTPS 域名（例如 `https://your-domain.example/`），不是 `example.invalid`。
- [ ] 手机设置页显示相同服务器地址和预期版本。
- [ ] Android 禁止明文 HTTP；错误证书连接会失败并显示明确提示。
- [ ] APK 为本次服务器接口通过冒烟后重新构建的版本。

## 四、目标手机 25 分钟阻断项

- [ ] 首次隐私说明、注册/登录正常。
- [ ] Android 13+ 拒绝通知权限时不能开始，并可跳转系统设置。
- [ ] 每轮都重新出现系统 MediaProjection 授权。
- [ ] 首帧立即上传，切换其他 App 后约每 20 秒继续采样。
- [ ] 持续录屏通知始终可见，返回专注页与结束操作有效。
- [ ] 同一提醒事件只通知一次，声音开关有效。
- [ ] 结束请求只结算一次，积分只发放一次。
- [ ] 报告与历史显示四态；低覆盖率明确显示“仅供参考”。
- [ ] 银行或密码管理器空白画面不会被判为确定分心。

## 五、异常场景阻断项

- [ ] 旋转屏幕不中断或重复创建 VirtualDisplay。
- [ ] 锁屏、系统停止共享和其他投屏任务触发时立即停止并结算。
- [ ] 断网期间不缓存、不补传截图；恢复网络后只处理新采集点。
- [ ] 模型响应超过 18 秒时取消本帧，并继续下一个采集点。
- [ ] App 重开后可通过本地 session ID 和 `/current` 恢复。
- [ ] 后端重启丢失会话时显示“本轮因服务重启未完整保存”且不伪造报告。
- [ ] 完成请求断网时 WorkManager 只重试无图片结算请求。
- [ ] APK、系统日志、DataStore 和缓存目录动态检查均无截图、Base64 截图、
  模型 API Key 或明文密码。

## 六、回滚演练

- [ ] 删除新增 Nginx `/api/v1/` location 后，旧网页版不受影响。
- [ ] 上一 release 可以重新启动。
- [ ] 运行数据备份可通过 `scripts/runtime_backup.py verify`。
- [ ] 未在非空生产 volume 上执行覆盖式恢复。

## 上线结论

- 任何阻断项未验证：结论只能写“未完成”，不能写“通过”。
- 自动化通过但未做真机测试：只允许内部安装，不交付实际用户。
- 完整通过后，记录最终提交、APK SHA-256、签名证书 SHA-256 和备份位置。
