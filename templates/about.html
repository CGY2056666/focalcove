前言与手册定位

本手册说明当前本地原型的操作方法、数据边界、已实现功能和后续规划，供使用者体验与开发者核对功能。实际能力以当前版本页面和运行结果为准；本页不是正式服务协议、隐私政策或效果承诺。

1

产品概述与设计思路

专注小窝是一款面向学习、办公、阅读和创作场景的专注辅助原型。你先写下本轮目标，主动选择一个屏幕、窗口或浏览器标签页作为分析范围；系统定时观察共享画面与目标是否相关，在需要时提醒，并在结束后保存记录。

它解决什么问题

  • 目标引导：用一条具体目标降低启动任务时的犹豫，并为后续画面判断提供上下文。
  • 轻量干预：提供低、中、高三档提醒，尽量只在符合条件时打断当前操作。
  • 完成反馈：把计划时长、实际时长、画面相关情况和提醒记录整理成一次可回看的报告。
  • 趣味激励：数据较完整的会话可以获得积分，积分可兑换并布置虚拟小窝装扮。

产品设计参考了目标设置、及时反馈、最小干预和代币激励等思路，但当前原型没有完成心理学有效性验证。模型只能判断共享画面与文字目标的相关程度，不能直接观察人的注意力、思考过程、情绪或任务完成质量。

2

账号注册、登录与个人设置

创建和使用账号

  • 当前注册只需要用户名和密码。用户名为 1–32 个中文、字母、数字、下划线或连字符，密码至少 8 个字符并同时包含字母和数字。
  • 注册成功后会直接登录；以后可以使用相同用户名和密码进入当前原型服务。
  • 专注历史、积分、已兑换装扮和小窝布局按当前账号保存在运行这套原型的电脑上。

个人设置

“个人设置”可以保存默认计划时长、默认提醒方式和提醒声音。每次开始前仍可修改这些选项。偏好保存在当前浏览器；换浏览器或清理浏览器数据后需要重新设置。

当前边界：手机号或邮箱注册、验证码登录、找回或修改密码、账号注销、多设备同步和异常账号处理尚未实现，均属于后续规划功能。请勿把本地原型账号用于存放重要或敏感资料。

3

开始一轮专注

第一步：写清楚目标

你可以从常用目标中选择，也可以输入自定义目标。页面最多接收 200 个字符，当前服务端取前 160 个字符作为分析目标。自定义目标是当前原型已经开放的基础功能，不需要会员。建议同时写清“对象”和“动作”，例如“阅读概率论教材第 3 章并整理例题”，通常比“学习”更便于判断。

第二步：设置计划时长

可设置 1–180 分钟。历史不足时系统通常给出 25 分钟参考；积累足够多的数据较完整记录后，系统会参考相同目标或相近目标类型生成建议。建议时长只是辅助，你可以采用，也可以直接输入更适合当下状态的时长。

第三步：选择提醒方式

低、中、高三档只改变提醒触发方式，不改变模型的单帧评分。大多数日常学习和办公可先使用“中：温和提醒”。

第四步：选择共享范围

点击“开始并选择共享范围”进入专注页，再点击“选择共享范围”，浏览器会显示自己的屏幕共享选择器。请选择本轮任务所在的标签页、窗口或屏幕，再确认共享。这个系统不能替你自动选中，也不能绕过浏览器权限。

  • 只共享一个任务窗口，通常更容易获得稳定、可解释的结果。
  • 如果要在多个应用之间切换，可共享整个屏幕，但应先关闭聊天、账号、密钥和其他敏感内容。
  • 关闭共享、刷新页面、浏览器休眠或网络中断都可能造成采集缺口。

屏幕分析、状态与三档提醒

屏幕怎样被分析

会话开始后通常立即采集首帧，此后约每 20 秒采集一次。浏览器会先缩放和压缩截图，再发送给服务端配置的视觉模型。静止或近似画面可能暂时复用上一结果；模型请求超时、网络错误或格式异常时，本帧会在规定时间内显示为“本次没有结果”，不会一直阻塞下一次采集。

画面与目标相关模型认为当前共享内容与目标相关，并有足够证据。
暂时无法判断通用工具、中立页面、切换过程或证据不足，不直接视为偏离。
画面可能偏离目标模型较明确地识别到当前画面与目标无关。
本次未能分析图片无效、超时、网络错误或返回异常，不计作相关或偏离。

画面任务相关度怎样产生

模型不直接给出总分，而是分别判断“目标内容相关度、实际任务证据、场景适配度、分心主导程度”四项 0–4 证据。服务端按 50% / 25% / 15% / 10% 合成基础分，再依据模型置信度向 50 分适度收缩，并只用过去最多 3 个独立画面做轻量因果平滑。这个 0–100 数值表示共享画面的任务相关证据，不是心理专注力、能力或完成质量。

状态和连续分彼此独立：类别与置信度决定是否为相关、不确定或偏离，连续分只用于趋势、报告和积分。通用工具、空白页、欢迎页或只有目标文字而没有实际任务内容的画面通常属于“不确定”，不会因为数字分数较低就变成偏离。

提醒规则

  • 低 · 安静记录：专注过程中不发实时提醒，只在结束后的记录中保留可能偏离的片段统计。
  • 中 · 温和提醒：检查最近约 60 秒；至少有 3 个有效结果、当前仍为偏离且窗口内偏离占比超过一半时提醒，之后约 120 秒内不重复提醒。
  • 高 · 及时提醒：高置信度的一次偏离可立即提醒，普通偏离通常需要连续出现；提醒后约 30 秒冷却，并在连续相关结果后重新允许提醒。

“暂时无法判断”和“本次未能分析”都不会触发提醒，也不会被当作恢复专注的证据。提醒以页面内固定提示条为主；个人设置中的声音开关决定是否播放提示音。浏览器系统通知尚未接入。

5

结束会话、报告与数据记录

结束与保存

到达计划时长后系统会自动结束；你也可以提前点击“结束并查看报告”。系统会停止浏览器采集，保存本轮历史，然后进入本轮报告。提前结束会如实记录实际时长和完成率，不会伪装成已完成。

报告包含什么

  • 本轮目标、目标类型、计划时长、实际时长和完成率。
  • 可用分析覆盖率、平均画面相关度，以及按采集节奏估算的相关和偏离时长。
  • 模型判为偏离的截图数、实际触发的提醒次数和本轮积分。

一轮记录要进入历史统计，需要同时满足：可用分析覆盖至少 70%、至少 3 张有效判断画面、明确判断时间占全部可评分时间至少 50%。覆盖合格但明确判断较少时仍会显示时间加权“参考分”，但不进入历史平均值、不发积分、不更新建议时长；全程都没有得到可用结果时不显示分数。

历史与导出

“专注记录”页会展示最近 14 天时长、近期数据较完整记录的画面相关度变化、各目标类型累计时长和历史会话列表。个人设置中可导出当前账号的 JSON 记录。周报、月报、年报以及 PDF 一键导出目前尚未实现，属于规划功能。

6

积分、装扮商店与我的小窝

积分怎样产生

本轮记录成功保存且数据较完整时，服务端会综合实际记录时长、平均画面任务相关度和覆盖率计算积分。覆盖不足、明确判断较少或旧版评分会话获得 0 分。积分是原型内的趣味反馈，不代表人的能力、学习质量，也不具有现金价值。

可以真实操作的内容

  • 装扮商店中的虚拟地板、墙面、家具和摆件可使用积分兑换。
  • 兑换价格由服务端校验；每件装扮只兑换一次，已拥有的物品不会重复扣分。
  • 进入“我的小窝”后，可以更换地板和墙面、摆放多个家具或装饰，并把当前布局保存到账号。

保留展示但尚未开放的奖励

音乐会员、平台会员、咖啡券、零食、饮品、购书额度和优惠券等仍保留在商店中作为奖励体系的原型预览，当前按钮不可兑换，不扣积分，也不对应真实会员、现金、优惠券、商品配送或其他实体权益。未来如接入真实合作方，会另行补充兑换、核销、退款与售后规则。

场景搭配与使用技巧

推荐搭配

  • 日常学习、写作与办公：目标写到具体章节或交付物，先用 25 分钟和中档提醒。
  • 考前冲刺或明确任务：共享单一任务窗口，使用高档提醒；若频繁误提醒，应退回中档并检查目标是否过于含糊。
  • 创意构思、资料搜索：搜索页面可能暂时难以判断，建议选择低档提醒，以结束后的记录为主。
  • 跨软件工作：必须在多个应用间切换时可共享整个屏幕，同时主动整理桌面并关闭敏感窗口。

怎样让结果更有参考价值

  • 将“大目标”拆成一轮能完成的小任务，例如从“写论文”改为“完成结果部分第一张图的解释”。
  • 不要把与任务相关的资料页和纯娱乐页频繁混在同一个标签页中。
  • 发现明显误判时，以实际任务为准；不要为了维持分数而改变合理的工作方式。
  • 先看多次记录的变化和具体偏离片段，不要用单次分数评价自己。

04评分与隐私说明模型边界、截图和本地数据
7

隐私、截图与数据边界

  • 你决定共享范围：系统只能看到你在浏览器选择器中主动确认的标签页、窗口或屏幕。可以随时停止共享或结束会话。
  • 截图会发送给模型：压缩后的画面会经本地服务端发送给配置的外部视觉模型进行判断，因此不要共享包含聊天记录、证件、支付信息、API Key 或其他敏感内容的窗口。
  • 默认不保存原始截图：普通专注历史主要保存时间、状态、分数和摘要，不默认把原始截图作为历史落盘。
  • 评测采样是例外：开发者显式开启本地评测采样时，首页会显示提示，部分去重截图会保存在本机等待人工复核。含敏感信息的候选应直接删除。
  • 账号数据位于原型服务：用户名、密码哈希、专注历史、积分和小窝数据保存在当前服务的本地数据文件中；浏览器偏好保存在当前浏览器。
  • 模型密钥不进入浏览器：模型 API Key 只由运行服务的开发者在服务端环境中配置。

这是可信本机或局域网内使用的单进程原型，不具备公网生产系统的完整认证、安全审计、跨设备同步和灾难恢复能力。使用前仍应由使用者自行确认共享内容是否合适。

开发中功能与原型限制

为了保留产品设计的完整构想，下列内容会继续出现在说明或奖励预览中，但当前版本不能按正式功能使用：

  • 账号能力规划：手机号或邮箱验证码、找回和修改密码、账号注销、跨设备同步。
  • 会员与权益规划：付费会员、会员专属功能、支付退款、音乐会员、优惠券、实体奖品兑换和物流售后。
  • 报告能力规划：自动生成周报、月报和年报，PDF 导出、社交分享和更完整的行为建议。
  • 服务能力规划：在线客服、工单反馈、浏览器系统通知和生产级多用户部署。

当前模型可能误判、超时或无法解析；浏览器休眠和共享中止会导致采样缺口；活动会话只保存在当前应用进程中。页面所显示的模型分数、建议时长和提醒都属于辅助反馈，不是医学、心理学或教育评价结论，也不应作为奖惩、考核或证明个人能力的依据。

版本更新与开发反馈

本手册会随原型功能、评分规则和页面入口一起更新。开发测试期间如发现功能问题，请通过项目开发者约定的渠道反馈，并尽量提供目标文本、提醒档位、浏览器、发生时间和可复现步骤；不要发送含账号、聊天、密钥或其他隐私信息的原始截图。

当前项目没有正式在线客服、服务时限或自动工单系统。若后续接入正式运营、付费权益或外部奖励，应由开发者在上线前补充联系方式、服务范围、兑换核销、退款售后和数据处理规则。
